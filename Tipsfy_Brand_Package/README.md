# Tipsfy — Brand Package

## Arquivos
- tipsfy-logo-horizontal.svg — logo principal
- tipsfy-logo-horizontal-white.svg — versão para fundos escuros
- tipsfy-logo-stacked.svg — versão vertical
- tipsfy-wordmark.svg — apenas nome
- tipsfy-icon.svg — símbolo T + seta
- tipsfy-icon-monochrome.svg — símbolo monocromático
- tipsfy-app-icon.svg — ícone de aplicativo
- tipsfy-color-palette.svg — paleta oficial
