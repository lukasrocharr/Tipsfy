Tipsfy SVG Pack

These SVGs are vector path traces generated from the supplied raster brand-board image.
They do not embed the original PNGs.

Includes SVG versions of:
- horizontal logos and color variations
- icon/mark color variations
- favicon/icon sizes
- standalone transparent mark
- brand color sheet

Brand colors:
#00E676
#0B0F14
#1F2937
#6B7280
#F8FAFC

Note: Because the source was a raster screenshot/brand board rather than an original SVG,
the vectors are traced approximations. For production-perfect geometry, the original
Figma/Illustrator/SVG source should be used if available.
